# Project 1: Healthcare Operations Dashboard

## Tool
Power BI Desktop

## Dataset
Kaggle Healthcare Dataset by Prasad Patil
56,000 patient records

## Files
- Healthcare_Dashboard_Saravana.pbix — Power BI file
- Healthcare_dashboard_saravanamoorthy.pdf — Dashboard PDF
- Healthcare_Dashboard_Screenshot.png — Dashboard Screenshot

## Visuals Built
- KPI Cards: Total Patients, Average Billing, Average Stay
- Bar Chart: Patients by Medical Condition
- Line Chart: Average Billing by Hospital
- Column Chart: Average Billing by Hospital
- Donut Chart: Patient Gender Distribution
- Slicers: Medical Condition, Gender

## Key Insights
1. All 6 medical conditions affect patients almost equally
2. Average hospital billing is 25,540
3. Gender split is exactly 50/50
